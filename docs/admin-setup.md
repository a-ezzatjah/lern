# راه‌اندازی مدیر سایت روی هاست ویندوز

ورود مشتری و مدیر مشترک است. نقش حساب تعیین می‌کند چه کسی به /Admin دسترسی دارد.

## تعیین اولین مدیر بدون دسترسی به ترمینال

1. سایت و دیتابیس را روی هاست راه‌اندازی کنید و با شمارهٔ متعلق به مدیر در سایت ثبت‌نام کنید.
2. در تنظیمات خصوصی برنامه روی سرور (فایل appsettings.Production.json کنار فایل‌های منتشرشده) تنظیم زیر را اضافه کنید. شمارهٔ نمونه را با شمارهٔ ثبت‌شده جایگزین کنید؛ دیگر تنظیمات موجود را حفظ کنید:

```json
{
  "InitialAdmin": {
    "Enabled": true,
    "PhoneNumber": "09xxxxxxxxx"
  }
}
```

3. سایت را از کنترل‌پنل هاست راه‌اندازی مجدد کنید. برنامه فقط اگر هیچ حساب Admin وجود نداشته باشد، حساب فعال همین شماره را مدیر می‌کند؛ حساب یا رمز تازه نمی‌سازد.
4. پس از موفقیت، بخش InitialAdmin را حذف کنید یا Enabled را false بگذارید و سایت را دوباره راه‌اندازی کنید. تنظیم راه‌اندازی اولیه نباید فعال باقی بماند.
5. از سایت خارج و دوباره وارد شوید؛ مسیر /Admin را باز کنید. مدیرهای بعدی از بخش کاربران پنل اضافه می‌شوند.

در صورت نبود حساب فعال، شمارهٔ نامعتبر یا وجود مدیر قبلی، حساب دیگری تغییر نمی‌کند. نتیجه در لاگ راه‌اندازی ثبت می‌شود؛ شماره و رمز در لاگ چاپ نمی‌شوند.

اگر پنل هاست متغیر محیطی برنامه را پشتیبانی کند، به‌جای فایل می‌توان InitialAdmin__Enabled=true و InitialAdmin__PhoneNumber را تنظیم کرد. اجرای این روش نیازمند دسترسی ترمینال نیست.

## دسترسی و استقرار

- کنترلرهای مدیریت فقط نقش Admin را می‌پذیرند؛ APIهای ایجاد، ویرایش و حذف محصول نیز محدود شده‌اند.
- نقش و فعال بودن حساب در هر درخواست ورودشده با دیتابیس تطبیق داده می‌شود؛ نقش حذف‌شده در کوکی قدیمی باقی نمی‌ماند.
- فایل تنظیمات سرور را در wwwroot نگذارید. رمز یا شمارهٔ ثابت مدیر در سورس قرار ندهید.
- روی هاست، اتصال SQL Server را با مشخصات واقعی دیتابیس تنظیم کنید؛ اتصال محلی Windows Authentication پروژه مناسب اتصال هاست نیست.
- قبل از استفادهٔ نهایی، اجرای ASP.NET Core 8، اتصال دیتابیس، SSL، امکان نوشتن فایل‌های آپلودی و ماندگاری کلیدهای Data Protection روی پلن خریداری‌شده بررسی شود.
