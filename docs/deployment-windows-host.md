# انتشار روی هاست ویندوز

1. روی سیستم توسعه `dotnet publish lern -c Release -o publish` را اجرا کنید.
2. محتوای پوشه `publish` را در ریشهٔ سایت هاست کپی کنید؛ فایل `web.config` همراه خروجی منتشر می‌شود.
3. در پنل هاست، نسخهٔ ASP.NET Core Hosting Bundle متناسب با .NET 8 و اتصال SQL Server را فعال کنید.
4. مقدار `ConnectionStrings:DefaultConnectionstring` و `Database:ApplyMigrationsOnStartup` را در تنظیمات محیطی هاست تنظیم کنید. برای اولین اجرا مقدار migration را فقط در زمان بروزرسانی `true` کنید و بعد خاموش کنید.
5. پس از ورود به پنل مدیریت، از «تنظیمات ← اتصال‌های فروشگاه» کلیدهای پیامک، درگاه و کد اینماد را ثبت کنید.

کلیدهای حساس از فرم دوباره نمایش داده نمی‌شوند و با Data Protection برنامه رمزگذاری می‌شوند. در هاست دائمی، کلیدهای Data Protection را در مسیر پایدار نگه دارید تا بعد از recycle قابل رمزگشایی باشند.
