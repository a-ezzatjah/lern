# تنظیمات سئو

- ویرایشگر تیترهای H1 تا H6، بولد و لینک داخلی و خارجی در درج/ویرایش مقاله، درج/ویرایش محصول و تنظیمات توضیحات دسته‌بندی فعال است.
- «تنظیمات ← توضیحات سئوی دسته‌بندی» متن قابل نمایش دسته، عنوان و توضیح متا را ذخیره می‌کند. نشانی اصلی دسته `/shop?category=ID` است؛ مسیر قبلی `/category/ID` به آن هدایت می‌شود.
- «نقشه سایت و ایندکس» اجازه index/noindex، follow/nofollow و عضویت در sitemap را مدیریت می‌کند. تنظیمات محصول با فرم محصول هماهنگ است.
- این صفحه چهار شاخه مستقل دارد: صفحه اصلی، محصولات، مقالات با گروه‌بندی دسته مقاله، و دسته‌بندی محصولات با تمام سطوح والد و فرزند. شاخه‌ها هنگام باز کردن و هر بار در بسته‌های ده‌تایی از سرور بارگیری می‌شوند؛ پایین آمدن در صفحه یا «بارگیری بیشتر» بسته بعدی را نمایش می‌دهد. لینک «مشاهده صفحه» در تب جدید باز می‌شود و ذخیره تنظیمات، شاخه بازشده را حفظ می‌کند.
- `/sitemap.xml` خودکار است و فقط محصولات فعال، مقالات منتشرشده و صفحات index انتخاب‌شده را دارد. با افزایش تعداد نشانی‌ها، نقشه به فایل‌های کوچک‌تر تقسیم می‌شود. صفحات دارای canonical اختصاصی برای جلوگیری از ارسال نشانی غیر اصلی، خودکار حذف می‌شوند.
- متن‌ها با HTML پاک‌سازی‌شده مستقیماً در پاسخ سرور نمایش داده می‌شوند. JavaScript برای خواندن متن توسط ربات لازم نیست. robots در meta و X-Robots-Tag خروجی دارد؛ صفحات جست‌وجو/فیلتر، حساب کاربری و مدیریت noindex هستند.
- هنگام استقرار، دامنه عمومی را در تنظیم `Seo:PublicOrigin` یا متغیر محیطی `Seo__PublicOrigin` قرار دهید، برای مثال `https://shop.example.com`. این دامنه برای canonical پیش‌فرض و sitemap استفاده می‌شود. اگر این تنظیم خالی باشد، دامنه درخواست استفاده می‌شود.
- در Search Console مالکیت دامنه را تأیید و `sitemap.xml` را ثبت کنید. با URL Inspection نسخه زنده صفحات را بررسی کنید. سایت محلی برای گوگل قابل دسترسی نیست؛ sitemap و index تضمین رتبه یا ایندکس نیستند.
- migration جدید `AddSeoPagesAndCategoryDescription` در شروع برنامه همراه migrationهای قبلی اعمال می‌شود.

آزمون: با سایت در حال اجرا روی پورت 5180، `dotnet run --project tools/SeoSmoke`. تغییرات آزمایشی پایگاه داده داخل تراکنش برگردانده می‌شوند.
